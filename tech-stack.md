# Tech Stack Overview

## Frontend
**React** to zdecydowanie dobry wybór ze względu na:
- Szybki rozwój interfejsu użytkownika.
- Szeroką społeczność i dostępność gotowych komponentów.
- Łatwość integracji z backendem.

## Backend
**Kotlin** wraz z **Spring Boot**, **Exposed** oraz **PostgreSQL** tworzą solidną podstawę backendu dzięki:
- Kotlin: nowoczesny, czytelny język.
- Spring Boot: ułatwia budowę API i integrację z narzędziami dzięki bogatemu ekosystemowi oraz wykorzystaniu **Spring Initializr** do szybkiego startu.
- Exposed: ułatwia operacje na bazie danych dzięki prostemu ORM dedykowanemu Kotlinowi.
- PostgreSQL: sprawdzona, niezawodna relacyjna baza danych, idealna do przechowywania danych zgodnie ze specyfiką aplikacji.

## AI
**Openrouter.ai** świetnie nadaje się do darmowej integracji z rozwiązaniami AI:
- Umożliwia łatwą komunikację z modelami AI.
- Otwarta i skalowalna platforma, co pozwala na szybkie wdrożenie funkcjonalności generowania flashcardów.

## CI/CD
**GitHub Actions** oraz **Docker** umożliwiają automatyzację procesów budowania, testowania i wdrażania:
- GitHub Actions: automatyzacja CI/CD, co przyspiesza rozwój projektu.
- Docker: zapewnia spójność środowisk poprzez konteneryzację, ułatwiając tworzenie, testowanie oraz wdrażanie aplikacji.
